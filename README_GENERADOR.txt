INVITACIÓN GITHUB PAGES - GENERADOR ACTUALIZABLE

1. Abre generador-enlaces.html en Chrome.
2. La dirección base ya está configurada:
   https://alejandroykatherinboda.github.io/invitacion-katherin-alejandro/
3. Selecciona tu nuevo archivo Excel.
4. Pulsa "Importar / actualizar Excel".
5. Verifica la tabla.
6. Pulsa "Descargar invitados.json".
7. En GitHub reemplaza:
   database/invitados.json
8. Guarda/commit los cambios y espera a que GitHub Pages publique.
9. Los enlaces se generan con:
   ?invitado=NUMERO

IMPORTANTE:
- El Excel debe tener columnas No., Nombre y Cantidad.
- Puedes volver a importar un Excel cuantas veces quieras.
- El generador guarda la última lista en el navegador.
- GitHub Pages no permite que una página web escriba directamente en tu repositorio; por eso el JSON actualizado se descarga y se reemplaza en GitHub.
- El diseño de la invitación no se modifica.

BOTONES:
- Copiar: copia el enlace personalizado.
- WhatsApp: abre WhatsApp con un mensaje y el enlace personalizado.
- Descargar JSON: genera el archivo que usa script.js.
- Descargar enlaces CSV: exporta todos los enlaces para control.
