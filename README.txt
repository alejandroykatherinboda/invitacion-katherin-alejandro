GENERADOR COMPARTIBLE - ALEJANDRO & KATHERIN

Listado incluido: 140 invitados.
Base de la invitación:
https://alejandroykatherinboda.github.io/invitacion-katherin-alejandro/

Para compartir el generador por Internet:
1. Sube generador-enlaces.html a la raíz de tu repositorio GitHub.
2. Sube database/invitados.json a la carpeta database/.
3. GitHub Pages lo publicará.
4. El enlace del generador será:
https://alejandroykatherinboda.github.io/invitacion-katherin-alejandro/generador-enlaces.html

El generador ya contiene el listado actual. También permite importar un Excel nuevo,
guardar la lista en el navegador, descargar invitados.json y descargar un XLSX con
enlaces y mensajes de WhatsApp.

Nota: al importar un Excel desde el generador compartido, el cambio se guarda en el
navegador de esa persona; no modifica automáticamente GitHub. Para actualizar la
lista pública de todos, descarga invitados.json y reemplázalo en GitHub.
